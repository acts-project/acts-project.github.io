Detailed Description

template<concepts::detector detector_t, typename node_inspector = void_node_inspector<typename detector_t::volume_type>, template< typename... > class vector_t = dvector>
struct detray::volume_graph< detector_t, node_inspector, vector_t >::edge_generator

Builds graph edges from the detector mask collection on the fly.

Iterates through the detectors mask store given a volume id (graph node) The graph edges are constructed for the node on the fly from the half edges in the _edges collection (detector masks).
