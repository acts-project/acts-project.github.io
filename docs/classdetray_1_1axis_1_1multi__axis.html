Detailed Description

template<bool ownership, typename local_frame_t, concepts::axis... axis_ts>
class detray::axis::multi_axis< ownership, local_frame_t, axis_ts >

An N-dimensional collection of single axes.

Given a point in the grid local coordinate system, which is spanned by the axes in this multi-axes type, the corresponding bin multi-index or multi-index range is returned.

Note
can be owning the data (as member of a standalone grid) or can be non-owning if the grid is part of a larger collection.

Get a bin range on every axis corresponding to the given point and the neighborhood around it.

The neighborhood around the point can be defined in two ways:

  • scalar: neighborhood around the axis value,
  • index: neighborhood in bins The resulting bin index range will contain all bins that belong to a given neighborhood around the lookup point.
