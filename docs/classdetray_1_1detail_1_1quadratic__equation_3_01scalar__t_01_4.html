Detailed Description

template<concepts::scalar scalar_t>
requires std::is_arithmetic_v<scalar_t>
class detray::detail::quadratic_equation< scalar_t >

Class to solve a quadratic equation of type a * x^2 + b * x + c = 0.

Note
If there are no real solutions, the result is undefined
The solutions are sorted by default. If there is only one solution, the larger value is undefined.
