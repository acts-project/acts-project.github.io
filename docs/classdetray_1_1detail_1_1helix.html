Detailed Description

template<concepts::algebra algebra_t>
class detray::detail::helix< algebra_t >

describes a helical trajectory in a given B-field.

Helix class for the analytical solution of track propagation in homogeneous B field. This Follows the notation of Eq (4.7) in DOI:10.1007/978-3-030-65771-0
