Detailed Description

Parameters of the detray surface grid of a volume.

Detray looks up a surface grid by intersecting the tangent of the track with a virtual reference surface and reading the bins in a search window around the crossing. A single bin (a [0, 0] window, detray's default) is the cheapest lookup, so the grid is filled for it: that bin lists every surface a track of the configured family can reach from there.
