Detailed Description

template<typename track_t, typename generator_t = detail::random_numbers<dscalar<typename track_t::algebra_type>>>
class detray::random_track_generator< track_t, generator_t >

Generates track states with random momentum directions.

Generates the phi and theta angles of the track momentum according to a given random number distribution.

Template Parameters
track_tthe type of track parametrization that should be used.
generator_tsource of random numbers
Note
Since the random number generator might not be copy constructible, neither is this generator. The iterators hold a reference to the rand generator, which must not be invalidated during the iteration.
the random numbers are clamped to fit the phi/theta ranges. This can effect distribution mean etc.
