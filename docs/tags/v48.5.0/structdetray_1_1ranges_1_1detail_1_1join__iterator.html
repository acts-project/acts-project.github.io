Detailed Description

template<detray::ranges::range range_t>
struct detray::ranges::detail::join_iterator< range_t >

Sequentially iterate through multiple ranges of the same type.

Once the sentinel of one range is reached, set the current iterator to the next ranges 'begin' (or 'end' if decrementing)

Template Parameters
range_ta range that contains the ranges to be joined.
