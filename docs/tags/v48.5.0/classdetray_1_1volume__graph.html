Detailed Description

template<concepts::detector detector_t, typename node_inspector = void_node_inspector<typename detector_t::volume_type>, template< typename... > class vector_t = dvector>
class detray::volume_graph< detector_t, node_inspector, vector_t >

Uses the geometry implementations to walk through their graph-like structure breadth first.

Template Parameters
detector_tthe type of geometry we want to walk along.
node_inspectorthe type of inspection to perform when a node is visited
Note
The detector has to expose the volume/portal interface.
