Detailed Description

template<class value_t, typename container_t = host_container_types>
class detray::brute_force_collection< value_t, container_t >

A collection of brute force surface finders, callable by index.

This class fulfills all criteria to be used in the detector multi_store .

Template Parameters
value_tthe entry type in the collection (e.g. surface descriptors).
container_tthe types of underlying containers to be used.
