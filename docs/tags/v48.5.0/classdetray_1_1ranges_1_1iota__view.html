Detailed Description

template<std::incrementable incr_t>
class detray::ranges::iota_view< incr_t >

Range factory that produces a sequence of values.

See also
https://en.cppreference.com/w/cpp/ranges/iota_view
Template Parameters
incr_tthe incrementable type that makes up the sequence
Note
If given single value, does not do infinite iteration, but only jumps to next value.
Is not fit for lazy evaluation.
