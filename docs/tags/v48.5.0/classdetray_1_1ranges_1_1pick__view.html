Detailed Description

template<std::input_iterator range_itr_t, std::input_iterator sequence_itr_t>
class detray::ranges::pick_view< range_itr_t, sequence_itr_t >

Range adaptor that indexes the elements of a range using another index range.

Template Parameters
range_itr_tthe iterator type of the enumerated range
sequence_itr_trange of indices.
Note
Does not take ownership of the range it operates on. Its lifetime needs to be guaranteed throughout iteration or between iterations with the same enumerate instance.
Is not fit for lazy evaluation.
