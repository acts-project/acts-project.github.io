Detailed Description

template<typename bin_t, template< std::size_t > class serializer_t, concepts::algebra algebra_t>
class detray::grid_factory< bin_t, serializer_t, algebra_t >

Provides functionality to instantiate grids and grid collections.

Template Parameters
bin_ttype bins in the grid
serialzier_ttype of the serializer to the storage representations
algebra_tthe matrix/vector/point types to use
container_tthe container types to use

throughout:

Note
that bin_edges is only used for variable binning
that if non-zero axis_spans are provided the values of the mask is overwritten
