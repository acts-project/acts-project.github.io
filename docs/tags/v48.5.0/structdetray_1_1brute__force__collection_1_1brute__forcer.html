Detailed Description

template<class value_t, typename container_t = host_container_types>
struct detray::brute_force_collection< value_t, container_t >::brute_forcer

A nested surface finder that returns all surfaces in a range (brute force).

This type will be returned when the surface collection is queried for the surfaces of a particular volume.
