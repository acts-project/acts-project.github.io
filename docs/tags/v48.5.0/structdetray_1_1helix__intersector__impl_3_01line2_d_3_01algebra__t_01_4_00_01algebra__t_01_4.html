Detailed Description

template<detray::concepts::aos algebra_t>
struct detray::helix_intersector_impl< line2D< algebra_t >, algebra_t >

Intersection implementation for helical trajectories with line surfaces.

The algorithm uses the Newton-Raphson method to find an intersection on the unbounded surface and then applies the mask.
