Detailed Description

template<typename material_t>
struct detray::detail::add_sf_material_map< material_t >

A functor to add a material map to a surface.

If deduplicate is set, an identical material map that is already in the material store is reused instead of adding a new one.

Returns
the type id and index of the material map in the store
