Detailed Description

template<concepts::type_registry registry_t, class type_selector_t>
class detray::types::mapped_registry< registry_t, type_selector_t >

Select a number of types from another registry and map their IDs to a continuous range of new type indices.

Note
Contrary to the original type registry, the type ID does not match the position of the filtered type in the mapped registry anymore
Template Parameters
registry_tthe original type registry
type_selector_thow to select the new types from the original ones
