class detray::hash_tree< input_collection_t, data_t, hash_function_t, hash_t, vector_t >

Builds a hash tree from the data of an input collection.

This class provides a graph algorithm that walk along the volumes of a given geometry and uses the portals to check reachability between the volumes.
