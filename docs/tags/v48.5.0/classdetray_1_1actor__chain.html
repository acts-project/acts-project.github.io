Detailed Description

template<concepts::actor... actors_t>
class detray::actor_chain< actors_t >

The interface to the actors and aborters in the propagation.

It can hold both simple actors, as well as an actor with its observers. The states of the actors need to be passed to the chain in an external tuple

Template Parameters
actors_tthe types of the actors in the chain.
