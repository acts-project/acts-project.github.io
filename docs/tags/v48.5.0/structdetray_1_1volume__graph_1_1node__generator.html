Detailed Description

template<concepts::detector detector_t, typename node_inspector = void_node_inspector<typename detector_t::volume_type>, template< typename... > class vector_t = dvector>
struct detray::volume_graph< detector_t, node_inspector, vector_t >::node_generator

Builds a graph node from the detector collections on the fly.

The node collection builds a graph node from a volume and the mask links in its surfaces, which are half edges of the graph. Every node has its index in the detector volume container and a vector of half edges.
