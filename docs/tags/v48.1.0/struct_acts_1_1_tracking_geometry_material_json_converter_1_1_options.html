unsigned int Acts::TrackingGeometryMaterialJsonConverter::Options::materialFractionBits {23}

Retained float fraction bits for built-in material properties and thickness, from 0 to 23.

The default preserves full precision; smaller values enable lossy rounding. Geometry coordinates are unaffected.
