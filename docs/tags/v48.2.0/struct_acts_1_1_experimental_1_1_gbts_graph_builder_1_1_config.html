bool Acts::Experimental::GbtsGraphBuilder::Config::calibrateStrips = true

Resolve a doublet's strip endpoints against its own direction before cutting on them.

Nothing is written back; the correction belongs to the pair.

◆ matchBeforeCreateMaxBarrelOrder

std::int32_t Acts::Experimental::GbtsGraphBuilder::Config::matchBeforeCreateMaxBarrelOrder = 1

Highest pixel barrel layer, counted inside out, to which matchBeforeCreate applies when it is enabled.

A negative value disables it.

◆ maxAbsTau

float Acts::Experimental::GbtsGraphBuilder::Config::maxAbsTau = 36.0f

Largest |cot(theta)| accepted for a doublet.

The default corresponds to |eta| of about 4.3, beyond the acceptance of any current tracker.

◆ maxStripLengthFraction

float Acts::Experimental::GbtsGraphBuilder::Config::maxStripLengthFraction = 1.1f

How far along a strip a crossing may land and still be recovered, as a multiple of the strip half-length, so 1 is the strip itself.

This is the same quantity as TripletSeedFinder::Config::toleranceParam.
