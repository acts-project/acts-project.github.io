struct Acts::ActorList< actors_t >

Composite actor that runs a list of actors.

The propagator runs a single actor. This actor combines several actors into one. It calls the actors in the order of the list. The act calls stop at the first failure, and the propagation aborts if any actor aborts.

The state of the composite holds the states of the actors that have one. Access them with actorState.get<actor_t::State>(). Each actor of the list gets its own entry as its actor state, not the whole composite state.

Note
The composite is fully responsible for the abort conditions of the propagation, like any other actor. Add DefaultActor to stop at the target surface and at the path limit. Put it first, so the loop protection sees the start momentum before other actors change it.
