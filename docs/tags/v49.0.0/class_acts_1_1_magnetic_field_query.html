Detailed Description

A field provider paired with its own reusable lookup cache.

Construct once per magnetic field context and reuse for sequential lookups. The provider and context are borrowed and must outlive the query. The context and any context-dependent data referenced by the cache must remain unchanged while the query is in use. Do not share a query between concurrent operations; construct independent queries for them (and for a new magnetic field context).
