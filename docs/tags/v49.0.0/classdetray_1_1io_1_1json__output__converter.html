Detailed Description

Class that converts a detector payload to json and writes it to file (single component per file).

This class writes every sub-payload of the detector payload that contains data into a separate json file, together with the respective file header.

Note
The class fulfills the output_file_converter_interface and can be added to the detector_components_output_converter
