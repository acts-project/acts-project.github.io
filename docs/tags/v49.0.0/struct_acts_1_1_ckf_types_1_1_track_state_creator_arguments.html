Detailed Description

template<typename traj_t>
struct Acts::CkfTypes::TrackStateCreatorArguments< traj_t >

The arguments of the track state creation on one surface.

Only the CKF makes this object, so it can get more fields without a change of the track state creator signature.

Note
It borrows everything it refers to for the duration of one call of the track state creator. Do not store it.
