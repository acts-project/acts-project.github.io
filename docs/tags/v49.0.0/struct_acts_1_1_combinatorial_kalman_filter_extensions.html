Definition CombinatorialKalmanFilterExtensions.hpp:60

Delegate the extension of the trajectory onto the surface of args.boundState to an external unit.

Note
Expected to create track states for measurements on that surface which match the predicted state. The "filtered" data is not expected to be set, but the outlier flag should be set for states that are considered to be outlier. A track state may have its own predicted parameters instead of sharing them.
Parameters
argsthe predicted state, the trajectory to extend, and the contexts
loggera logger for messages
Returns
indices of new track states which extend the trajectory given by args.prevTip. Each one must be a measurement or an outlier, otherwise the CKF fails with CombinatorialKalmanFilterError::UnsupportedTrackState. An empty list means that the CKF creates a hole, the error CombinatorialKalmanFilterError::NoMeasurementExpected that it creates a state without an expected measurement.
