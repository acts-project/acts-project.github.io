Detailed Description

Flags seeds whose measurements one accepted track already holds.

Measurements are dense keys in [0, nMeasKeys). The caller chooses which keys a seed contributes. The keys are plain indices and not SourceLinks, because a SourceLink has no hash and no equality comparison.

Each key has a weight, 1 by default. The weight can for example be the number of measured local coordinates, so that a pixel measurement counts 2 and a strip measurement counts 1. A seed with the summed weight seedScore is a duplicate if one track holds keys of the summed weight

min(seedScore, max(1, minScore, seedScore - maxMissingScore)).

The scores of different tracks do not add up. Seeds can be queried in any order.
