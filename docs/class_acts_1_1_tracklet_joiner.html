Detailed Description

Join a second tracklet, filtered from a state of a smoothed first tracklet as prior, behind that shared state, and combine their smoothed estimates without a new propagation.

This is the two-way track finding.

A smoother over the stitched chain would count the first tracklet twice. Instead the second tracklet is smoothed alone and one smoothing step carries its information onto the shared state; the change of the shared state is transported to the first tracklet by conditioning (detail::conditionSmoothedStatesOnSharedState); then the chains are linked (detail::linkTrackletBehind).

With smoothing and conditioning enabled, the smoothed states hold both tracklets. Unsmoothed trailing states of the first tracklet stay unchanged. States of the first tracklet before the shared state leave the chain. The predicted and filtered history stays in two filter orders, so a later smoother over the joined chain is invalid. The track-level data is taken from the second tracklet. If the second tracklet has no states, only its track-level data is copied; this covers propagation to the target without another detector surface.

Join in place: the first tracklet becomes the joined track.

It must own its states; with several second tracklets use joinCopy. Both tracklets must use the same trajectory and own disjoint states. If the first tracklet is not linked forward, this links it forward. On failure, smoothed states may already have been modified.
