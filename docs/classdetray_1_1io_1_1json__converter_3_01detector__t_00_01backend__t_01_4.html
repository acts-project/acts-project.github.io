Detailed Description

template<class detector_t, class backend_t>
requires concepts::reader_backend<detector_t, backend_t>
class detray::io::json_converter< detector_t, backend_t >

Class that adds json functionality to backend reader types.

Class that adds json functionality to backend writer types.

Assemble the json readers from the backend reader types, which handle the volume builders, and this class, which provides the payload data from the json stream. It also includes the respective to_json and from_json functions for the payloads ("json_serializers").

Note
The resulting reader types will fulfill reader_interface

Assemble the json writers from the backend writer types, which serialize a detector into the io payloads, and this class, which does the file handling and provides the json stream. It also includes the respective to_json and from_json functions for the payloads ("json_serializers").

Note
The resulting writer types will fulfill writer_interface
