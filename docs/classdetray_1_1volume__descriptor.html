Detailed Description

template<typename ID, typename acc_link_t = dtyped_index<dindex, dindex>, typename mat_link_t = dtyped_index<dindex, dindex>>
class detray::volume_descriptor< ID, acc_link_t, mat_link_t >

The detray detector volume descriptor.

Contains the data and links to describe a detector volume. This is the type that is stored in the detector data stores.

Template Parameters
IDenum of object types contained in the volume (
See also
default_metadata ).
Template Parameters
link_tthe type of link to the volumes surfaces finder(s) (accelerator structure, e.g. a grid). The surface finder types cannot be given directly, since the containers differ between host and device. The surface finders reside in an 'unrollable tuple container' and are called per volume in the navigator during local navigation.

How to access objects (e.g.

sensitives/passives/portals) in this volume. Keeps one accelerator structure link per object type (by ID):

acc_link_t : id and index of the accelerator structure in the detector's surface store.

E.g. a 'portal' can be found under ID::e_portal in this link, and will then receive link to the brute_force acceleration structure that holds the portals (the accelerator structure's id and index).
