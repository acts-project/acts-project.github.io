Detailed Description

template<concepts::detector detector_t, typename index_t = dindex>
class detray::material_map_factory< detector_t, index_t >

Factory class for material maps.

Uses a surface factory underneath the hood that handles the surface construction. The material ID from the detector determines the type of material map that will be produced. The factory is filled from [a vector] of material_data .

Template Parameters
detector_ttype of detector that contains the material
index_tlocal bin index type

Add data for material maps to the containers of a volume builder.

This assumes that the surfaces have already been added (e.g. by this factories underlying surface factory).

Note
This does not override the pure virtual function from the surface factory interface, but presents an overload for the case when material should be added.
Parameters
surfacessurface container of the volume builder that should get decorated with material maps.
material_mapmap the local bin indices and their content to a volume local surface index.
n_binsNumber of bins on each axis for every mapped surface.
axis_spansCoordinate spans for each material-map axis.
Returns
No value; material data is added to the output containers.
