Detailed Description

template<typename value_t>
class detray::ranges::single_view< value_t >

Struct that implements a view on a single element.

See also
https://en.cppreference.com/w/cpp/ranges/single_view
Template Parameters
value_ttype of the single element (outside of a container)
Note
Does not take ownership of the value it operates on. Its lifetime needs to be guaranteed throughout iteration or between iterations with the same view instance.
Is not fit for lazy evaluation.
