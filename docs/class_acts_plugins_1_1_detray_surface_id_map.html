Detailed Description

Two-way map between ACTS and detray surface identifiers.

The detray surface identifiers are only assigned when the detray detector is built, so the map is created from the built detector. The DetrayPayloadConverter stores the ACTS geometry identifier of every surface as its detray source link, which is what the map is built from.

Besides the identifiers, the map also gives direct access to the ACTS surface of every mapped detray surface. Device code cannot hold pointers, so the detray identifier stays the key that is passed around, e.g. as the surface link of traccc track parameters.

Only sensitive surfaces are mapped: they have unique ACTS geometry identifiers, while e.g. a single ACTS portal can be split into several detray portals.

The map cannot be changed after construction. Only the surface transforms change with alignment, and those are handled through the geometry context.

Note
The map holds non-owning pointers to the ACTS surfaces, so the tracking geometry has to outlive it.
