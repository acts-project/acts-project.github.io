Detailed Description

template<concepts::algebra algebra_t, typename mask_shape_t = rectangle2D>
struct detray::telescope_metadata< algebra_t, mask_shape_t >

Defines a special telescope test detector type with only rectangle portals and one additional kind of contained module surfaces (mask_shape_t).
