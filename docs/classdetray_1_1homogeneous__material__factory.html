Detailed Description

template<concepts::detector detector_t>
class detray::homogeneous_material_factory< detector_t >

Factory class for homogeneous material.

Uses a surface factory underneath the hood that handles the surface construction. The material ID from the detector determines the type of material that will be produced. The factory is filled from [a vector] of material_data .

Template Parameters
detector_ttype of detector that contains the material

typename detector_t::material_container & materials )

Add material to the containers of a volume builder.

This assumes that the surfaces have already been added (e.g. by this factories underlying surface factory). The material from this factory is added to the corresponding number of surfaces at the end of the calling volume builder.

Note
This does not override the pure virtual function from the surface factory interface, but presents an overload for the case when material should be added.
Parameters
surfacessurface container of the volume builder that should get decorated with material.
materialsmaterial store of the volume builder that the new materials get added to.
Returns
No value; surfaces and material storage are updated in place.
