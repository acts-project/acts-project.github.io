Detailed Description

template<concepts::metadata metadata_t, typename container_t>
class detray::detail::detector< metadata_t, container_t >

The detector definition.

This class is a heavily templated container aggregation, that owns all data. Its view type is used to move the data between host and device. It is constructed by the detector_builder and is afterwards immutable.

Template Parameters
metadatahelper that defines collection and link types centrally
container_ttype collection of the underlying containers
