Detailed Description

template<std::size_t N, concepts::scalar scalar_t, template< typename, std::size_t > class array_t>
class detray::algebra::storage::vector< N, scalar_t, array_t >

Vector wrapper for AoS vs interleaved SoA data.

scalar_t can e.g. be a SIMD vector.
