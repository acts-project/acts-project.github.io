Detailed Description

Class that reads json data from file and converts it to a detector payload (single component per file).

This class provides the payload data from the json stream and adds it to the sub-payload of the detector component that is tagged in the file

Note
The class fulfills the input_file_converter_interface and can be added to the detector_components_converter
