Detailed Description

template<typename value_t = std::uint64_t>
class detray::detail::bit_encoder< value_t >

Sets masked bits to a given value.

Given a mask and an input value, the corresponding bits are set on a target value. Used e.g. in the surface identifier.

https://github.com/acts-project/acts/blob/main/Core/include/Acts/Geometry/GeometryIdentifier.hpp
